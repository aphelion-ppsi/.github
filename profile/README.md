## Proyek Unggulan

### Contract360

**Sistem Manajemen Kontrak dan Rekonsiliasi Tagihan**

Contract360 merupakan platform untuk pengelolaan kontrak, rekonsiliasi tagihan telekomunikasi, dan pemrosesan dokumen kontrak untuk Telkom Indonesia.

#### Fitur Utama

- **Manajemen Kontrak:** Pengelolaan data pelanggan, kontrak, dan item layanan.
- **Ekstraksi Dokumen Berbantuan AI:** Ekstraksi informasi dari dokumen kontrak menggunakan Vision OCR dengan verifikasi oleh pengguna.
- **Rekonsiliasi Tagihan:** Pencocokan data tagihan dengan nilai layanan berdasarkan kontrak.
- **Deteksi Tagihan Tanpa Kontrak:** Identifikasi tagihan yang tidak memiliki kontrak pendukung.
- **Dashboard Eksekutif:** Ringkasan indikator kinerja, data kontrak, dan informasi rekonsiliasi.
- **Otomatisasi Proses:** Impor data tagihan, pemrosesan asinkron, dan notifikasi.
